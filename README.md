# Hướng Dẫn Tạo Fixed Top Menu trong CSS

Bài thực hành tạo thanh menu điều hướng cố định ở mép trên màn hình (Fixed Navigation Bar).

## Các thuộc tính CSS quan trọng
- **\position: fixed\**: Giữ thanh menu cố định tại một vị trí trên màn hình dù người dùng cuộn trang lên hay xuống.
- **\	op: 0\**: Đặt menu gắn chặt ở mép trên cùng của khung nhìn trình duyệt.
- **\width: 100%\**: Độ rộng của menu mở rộng 100% bằng toàn bộ chiều ngang trình duyệt.
- **\margin-top: 60px\** (cho khối nội dung chính): Đẩy nội dung xuống để không bị thanh menu che khuất dòng đầu tiên.
